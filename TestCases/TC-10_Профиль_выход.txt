Таблица TC-10 – Тест-кейс профиля пользователя и выхода из системы
+------------------------------------------------------------------+------------------------------------------+----------+
| Тест                                                             | Ожидаемый результат                      | Результат|
+------------------------------------------------------------------+------------------------------------------+----------+
| Просмотр профиля пользователя                                    | 1 Открывается вкладка «Настройки».       | Успех    |
| 1 Войти в приложение.                                            | 2 Раздел «Профиль» отображается          |          |
| 2 Перейти на вкладку «Настройки».                                |   в верхней части страницы.              |          |
| 3 Нажать кнопку «›» в разделе «Профиль».                        | 3 Открывается страница профиля.          |          |
| 4 Проверить элементы страницы профиля.                           | 4 Отображаются: имя пользователя,        |          |
|                                                                  |   email, статус Premium                  |          |
|                                                                  |   (Активен / Неактивен),                 |          |
|                                                                  |   кнопка «Выйти».                        |          |
+------------------------------------------------------------------+------------------------------------------+----------+
| Выход из системы                                                 | 1 Страница профиля открыта.              | Успех    |
| 1 Открыть страницу профиля.                                      | 2 Кнопка «Выйти» найдена.               |          |
| 2 Найти кнопку «Выйти».                                          | 3 Кнопка нажата.                         |          |
| 3 Нажать кнопку «Выйти».                                         | 4 Сессия завершается, пользователь       |          |
| 4 Проверить результат.                                           |   перенаправляется на страницу входа.    |          |
|                                                                  |   Данные сессии очищены: повторное       |          |
|                                                                  |   открытие приложения показывает         |          |
|                                                                  |   экран входа, а не Dashboard.           |          |
+------------------------------------------------------------------+------------------------------------------+----------+
| Проверка статуса Premium                                         | 1 Страница профиля открыта.              | Успех    |
| 1 Открыть страницу профиля.                                      | 2 Статус Premium отображается.           |          |
| 2 Проверить статус Premium.                                      | 3 Для пользователя без Premium:          |          |
| 3 Перейти на страницу Premium (если доступна).                   |   статус «Неактивен».                    |          |
| 4 Нажать «Купить Premium».                                       | 4 Выполняется имитация покупки.          |          |
| 5 Вернуться в профиль и проверить статус.                        | 5 Статус обновляется на «Активен».       |          |
|                                                                  |   Отображается сообщение                 |          |
|                                                                  |   «Премиум активирован!».                |          |
