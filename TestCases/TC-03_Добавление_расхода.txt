Таблица TC-03 – Тест-кейс добавления расхода
+------------------------------------------------------------------+------------------------------------------+----------+
| Тест                                                             | Ожидаемый результат                      | Результат|
+------------------------------------------------------------------+------------------------------------------+----------+
| Успешное добавление расхода                                      | 1 Открывается вкладка «Расходы».         | Успех    |
| 1 Войти в приложение.                                            | 2 Отображается список расходов           |          |
| 2 Перейти на вкладку «Расходы».                                  |   (или сообщение «Пока нет расходов»)    |          |
| 3 Нажать кнопку добавления расхода («+»).                        |   и кнопка добавления.                   |          |
| 4 Проверить элементы формы добавления.                           | 3 Открывается форма добавления расхода.  |          |
| 5 Ввести сумму (например, 150.00).                               | 4 Отображаются поля: Сумма, Дата,        |          |
| 6 Выбрать категорию из списка.                                   |   Категория, Комментарий, кнопки         |          |
| 7 Выбрать дату.                                                  |   «Сохранить» и «Отмена».               |          |
| 8 Ввести комментарий (необязательно).                            | 5 Сумма введена.                         |          |
| 9 Нажать кнопку «Сохранить».                                     | 6 Категория выбрана.                     |          |
|                                                                  | 7 Дата выбрана.                          |          |
|                                                                  | 8 Комментарий введён.                    |          |
|                                                                  | 9 Форма закрывается, новый расход        |          |
|                                                                  |   появляется в списке с корректными      |          |
|                                                                  |   суммой, категорией и датой.            |          |
+------------------------------------------------------------------+------------------------------------------+----------+
| Добавление расхода с нулевой суммой                              | 1–3 Форма добавления открыта.            | Успех    |
| 1–3 Открыть форму добавления расхода.                            | 4 Сумма = 0.                             |          |
| 4 Ввести сумму 0.                                                | 5 Категория выбрана.                     |          |
| 5 Выбрать категорию.                                             | 6 Отображается сообщение об ошибке:      |          |
| 6 Нажать «Сохранить».                                            |   «Сумма должна быть положительной».     |          |
|                                                                  |   Расход не сохраняется.                 |          |
+------------------------------------------------------------------+------------------------------------------+----------+
| Добавление расхода без выбора категории                          | 1–3 Форма добавления открыта.            | Успех    |
| 1–3 Открыть форму добавления расхода.                            | 4 Сумма введена.                         |          |
| 4 Ввести корректную сумму.                                       | 5 Категория не выбрана.                  |          |
| 5 Не выбирать категорию.                                         | 6 Отображается сообщение об ошибке:      |          |
| 6 Нажать «Сохранить».                                            |   «Выберите категорию».                  |          |
|                                                                  |   Расход не сохраняется.                 |          |
