| Успешное добавление дохода                                       | 1 Открывается вкладка «Доходы».          | Успех    |
| 1 Войти в приложение.                                            | 2 Отображается список доходов            |          |
| 2 Перейти на вкладку «Доходы».                                   |   (или «Пока нет доходов») и кнопка      |          |
| 3 Нажать кнопку добавления дохода («+»).                         |   добавления.                            |          |
| 4 Проверить элементы формы добавления.                           | 3 Открывается форма добавления дохода.   |          |
| 5 Ввести сумму (например, 2500.00).                              | 4 Отображаются поля: Сумма, Источник,    |          |
| 6 Ввести источник дохода (например, «Зарплата»).                 |   Дата, Комментарий, кнопки              |          |
| 7 Выбрать дату.                                                  |   «Сохранить» и «Отмена».               |          |
| 8 Нажать кнопку «Сохранить».                                     | 5 Сумма введена.                         |          |
|                                                                  | 6 Источник введён.                       |          |
|                                                                  | 7 Дата выбрана.                          |          |
|                                                                  | 8 Форма закрывается, новый доход         |          |
|                                                                  |   появляется в списке с корректными      |          |
|                                                                  |   суммой, источником и датой.            |          |
+------------------------------------------------------------------+------------------------------------------+----------+
| Добавление дохода без указания источника                         | 1–3 Форма добавления открыта.            | Успех    |
| 1–3 Открыть форму добавления дохода.                             | 4 Сумма введена.                         |          |
| 4 Ввести корректную сумму.                                       | 5 Поле «Источник» пустое.                |          |
| 5 Оставить поле «Источник» пустым.                               | 6 Отображается сообщение об ошибке:      |          |
| 6 Нажать «Сохранить».                                            |   «Укажите источник».                    |          |
|                                                                  |   Доход не сохраняется.                  |          |
+------------------------------------------------------------------+------------------------------------------+----------+
| Добавление дохода с отрицательной суммой                         | 1–3 Форма добавления открыта.            | Успех    |
| 1–3 Открыть форму добавления дохода.                             | 4 Введена отрицательная сумма.           |          |
| 4 Ввести сумму -500.                                             | 5 Источник введён.                       |          |
| 5 Ввести источник.                                               | 6 Отображается сообщение об ошибке:      |          |

|                                                                  |   Доход не сохраняется.                  |          |
