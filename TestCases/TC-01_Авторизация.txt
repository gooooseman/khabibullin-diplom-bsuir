Таблица TC-01 – Тест-кейс авторизации пользователя
+------------------------------------------------------------------+------------------------------------------+----------+
| Тест                                                             | Ожидаемый результат                      | Результат|
+------------------------------------------------------------------+------------------------------------------+----------+
| Вход с корректными данными                                       | 1 Открывается страница входа.            | Успех    |
| 1 Открыть приложение.                                            | 2 Отображаются поля Email и Пароль,      |          |
| 2 Проверить элементы на странице входа.                          |   кнопка «Войти» и ссылка               |          |
| 3 Ввести зарегистрированный email в поле Email.                  |   «Регистрация».                         |          |
| 4 Ввести корректный пароль в поле Пароль.                        | 3 Поле Email активно, курсор             |          |
| 5 Нажать кнопку «Войти».                                         |   установлен.                            |          |
|                                                                  | 4 Символы пароля скрыты                  |          |
|                                                                  |   (точки/звёздочки).                     |          |
|                                                                  | 5 Пользователь перенаправляется          |          |
|                                                                  |   на главный экран (Dashboard).          |          |
|                                                                  |   Отображается приветствие               |          |
|                                                                  |   «Привет, <логин>».                     |          |
+------------------------------------------------------------------+------------------------------------------+----------+
| Вход с неверным паролем                                          | 1 Открывается страница входа.            | Успех    |
| 1 Открыть приложение.                                            | 2 Поля отображаются корректно.           |          |
| 2 Ввести зарегистрированный email.                               | 3 Email введён.                          |          |
| 3 Ввести неверный пароль.                                        | 4 Пароль введён (скрыт).                 |          |
| 4 Нажать кнопку «Войти».                                         | 5 Появляется сообщение об ошибке:        |          |
|                                                                  |   «Ошибка входа. Проверьте данные.»      |          |
|                                                                  |   Переход на Dashboard не происходит.    |          |
+------------------------------------------------------------------+------------------------------------------+----------+
| Вход с пустыми полями                                            | 1 Открывается страница входа.            | Успех    |
| 1 Открыть приложение.                                            | 2 Поля пусты.                            |          |
| 2 Не заполнять поля Email и Пароль.                              | 3 Кнопка «Войти» не реагирует           |          |
| 3 Нажать кнопку «Войти».                                         |   или отображается валидационное         |          |
|                                                                  |   сообщение. Вход не выполняется.        |          |
