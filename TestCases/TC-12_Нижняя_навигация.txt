Таблица TC-12 – Тест-кейс нижней навигационной панели
+------------------------------------------------------------------+------------------------------------------+----------+
| Тест                                                             | Ожидаемый результат                      | Результат|
+------------------------------------------------------------------+------------------------------------------+----------+
| Отображение нижней навигационной панели                          | 1 Выполнен вход в приложение.            | Успех    |
| 1 Войти в приложение.                                            | 2 Нижняя панель навигации отображается   |          |
| 2 Проверить наличие нижней панели навигации.                     |   на всех основных экранах.              |          |
| 3 Проверить наличие иконок и подписей вкладок.                   | 3 Панель содержит 6 вкладок с иконками   |          |
|                                                                  |   и подписями:                           |          |
|                                                                  |   – 🏠 Главная (домик);                  |          |
|                                                                  |   – ↑ Доходы (стрелка вверх);            |          |
|                                                                  |   – ↓ Расходы (стрелка вниз);            |          |
|                                                                  |   – 📊 Аналитика (столбчатый график);    |          |
|                                                                  |   – 🎯 Цели (мишень);                    |          |
|                                                                  |   – ⚙ Настройки (шестерёнка).            |          |
+------------------------------------------------------------------+------------------------------------------+----------+
| Переключение между вкладками                                     | 1 Открыта вкладка «Главная».             | Успех    |
| 1 Открыть вкладку «Главная».                                     | 2 Нажата вкладка «Расходы».              |          |
| 2 Нажать на вкладку «Расходы».                                   | 3 Открывается страница расходов,         |          |
| 3 Проверить переход.                                             |   иконка «Расходы» становится активной   |          |
| 4 Нажать на вкладку «Аналитика».                                 |   (выделена цветом).                     |          |
| 5 Проверить переход.                                             | 4 Нажата вкладка «Аналитика».            |          |
|                                                                  | 5 Открывается страница аналитики,        |          |
|                                                                  |   иконка «Аналитика» активна.            |          |
+------------------------------------------------------------------+------------------------------------------+----------+
| Перевод подписей вкладок при смене языка                         | 1 Открыта вкладка «Настройки».           | Успех    |
| 1 Перейти на вкладку «Настройки».                                | 2 Язык «English» выбран.                 |          |
| 2 Сменить язык на «English».                                     | 3 Диалог подтверждён.                    |          |
| 3 Подтвердить диалог.                                            | 4 Подписи вкладок нижней панели          |          |
| 4 Проверить подписи вкладок нижней панели.                       |   переключаются на английский:           |          |
|                                                                  |   Dashboard, Income, Expense,            |          |
|                                                                  |   Analytics, Goals, Settings.            |          |
|                                                                  |   Кнопка «More» не отображается.         |          |
+------------------------------------------------------------------+------------------------------------------+----------+
