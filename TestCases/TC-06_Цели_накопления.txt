Таблица TC-06 – Тест-кейс управления целями накопления
+------------------------------------------------------------------+------------------------------------------+----------+
| Тест                                                             | Ожидаемый результат                      | Результат|
+------------------------------------------------------------------+------------------------------------------+----------+
| Создание новой цели накопления                                   | 1 Открывается вкладка «Цели».            | Успех    |
| 1 Войти в приложение.                                            | 2 Отображается список целей              |          |
| 2 Перейти на вкладку «Цели».                                     |   (или «Пока нет целей») и кнопка «+».  |          |
| 3 Нажать кнопку добавления цели («+»).                           | 3 Открывается форма создания цели.       |          |
| 4 Проверить элементы формы.                                      | 4 Отображаются поля: Название цели,      |          |
| 5 Ввести название цели (например, «Отпуск»).                     |   Целевая сумма, Текущие накопления,     |          |
| 6 Ввести целевую сумму (например, 5000).                         |   Срок, кнопки «Сохранить» и «Отмена». |          |
| 7 Ввести начальные накопления (например, 500).                   | 5 Название введено.                      |          |
| 8 Выбрать срок (например, 31.12.2025).                           | 6 Целевая сумма введена.                 |          |
| 9 Нажать «Сохранить».                                            | 7 Начальные накопления введены.          |          |
|                                                                  | 8 Срок выбран.                           |          |
|                                                                  | 9 Форма закрывается, новая цель          |          |
|                                                                  |   появляется в списке с прогресс-баром,  |          |
|                                                                  |   отражающим 500/5000 (10%).             |          |
+------------------------------------------------------------------+------------------------------------------+----------+
| Пополнение существующей цели                                     | 1 Вкладка «Цели» открыта,               | Успех    |
| 1 Перейти на вкладку «Цели».                                     |   цель «Отпуск» присутствует.            |          |
| 2 Нажать кнопку «Пополнить» у цели «Отпуск».                    | 2 Появляется диалог ввода суммы          |          |
| 3 Ввести сумму пополнения (например, 1000).                      |   пополнения.                            |          |
| 4 Подтвердить пополнение (нажать «OK»).                          | 3 Сумма 1000 введена.                    |          |
| 5 Проверить обновление прогресса.                                | 4 Диалог закрывается.                    |          |
|                                                                  | 5 Прогресс цели обновляется:             |          |
|                                                                  |   накопления увеличиваются на 1000,      |          |
|                                                                  |   прогресс-бар отражает новое значение.  |          |
+------------------------------------------------------------------+------------------------------------------+----------+
| Создание цели с нулевой целевой суммой                           | 1–3 Форма создания цели открыта.         | Успех    |
| 1–3 Открыть форму создания цели.                                 | 4 Название введено.                      |          |
| 4 Ввести название.                                               | 5 Целевая сумма = 0.                     |          |
| 5 Ввести целевую сумму 0.                                        | 6 Отображается сообщение об ошибке:      |          |
| 6 Нажать «Сохранить».                                            |   «Целевая сумма должна быть             |          |
|                                                                  |   положительной». Цель не сохраняется.   |          |
